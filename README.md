## Day 3 – Agile and Scrum Assignments

Contains three application-based assignments:

1. **Online Grocery Delivery Application**
2. **Insurance Claims Portal**
3. **Hospital Appointment Booking Application**

Each set includes a DOCX document explaining the completed assignment and an individual README file describing its contents.

## Day 4 – Scrum Simulation Assignments

Contains three scenario-based Scrum exercises:

1. **Digital Wallet Application** – Sprint planning, velocity calculation, task estimation, mid-sprint scope changes, impediment management and burndown tracking.
2. **Airline Web Check-in** – Team capacity calculation, Definition of Ready, dependency management, backlog refinement, Sprint Review and asynchronous stand-up.
3. **E-Learning Platform** – Sprint planning, scope change handling, API dependency management, velocity calculation, retrospective and Definition of Done automation.

Each set includes its DOCX documentation, Jira sprint report PDF, individual README file and relevant screenshots.

## Tools Used

- **Jira** – Scrum project and sprint management
- **Microsoft Word** – Assignment documentation
- **PDF** – Sprint reports
- **Markdown** – README documentation

This repository maintains all six practical assignments in an organized structure for easy access and reference.
