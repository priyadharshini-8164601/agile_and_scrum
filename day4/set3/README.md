# Set 3 – E-Learning Platform

This folder contains the completed Jira Scrum assignment for the E-Learning Platform scenario. It documents sprint planning, a Day 6 scope change, dependency management, velocity calculation, retrospective activities and automation supporting the Definition of Done.

## Files Description

- **Set3_E_Learning_Platform.docx** – Detailed documentation of the Jira work, including space and Epic creation, user stories, sprint planning, scope-change handling, the missing API contract impediment, velocity calculation, retrospective and Definition of Done automation.
- **report.pdf** – Actual sprint report exported from Jira.
- **README.md** – Overview of the assignment and folder structure.
- **Screenshots/** – Screenshots showing the Jira space, Epic and stories, and sprint board.
