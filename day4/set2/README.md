# Set 2 – Airline Web Check-in

This folder contains the completed Jira Scrum assignment for the Airline Web Check-in application.

The project demonstrates Agile and Scrum practices for sprint planning, managing external dependencies, backlog refinement, Sprint Review and team communication.

## Folder Structure

```text

    ├── 01_Space_Creation.png

```

## Files Description

- **Set2_Airline_Web_Check-in.docx** – Detailed documentation of the Jira activities, capacity calculation, sprint planning, Definition of Ready, impediment management, backlog refinement, Sprint Review and asynchronous stand-up.
- **report.pdf** – Exported Jira sprint report.
- **README.md** – Overview of the assignment and folder structure.
- **Screenshots/** – Screenshots showing the Jira space, Epic, user stories and sprint board.

## Topics Covered

- Jira Scrum space creation
- Epic and user story creation
- Team capacity calculation
- Sprint planning and Sprint Goal
- Definition of Ready (DoR)
- Impediment identification and resolution
- Product backlog refinement
- Splitting and estimating user stories
- Sprint Review agenda and demonstration
- Asynchronous Daily Scrum
- Comparison of asynchronous and live stand-ups

## Tools Used

- Jira – Agile project and sprint management
- Microsoft Word – Project documentation
- PDF – Sprint report

This assignment demonstrates practical Scrum project management using an Airline Web Check-in scenario.
