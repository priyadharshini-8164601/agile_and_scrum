# Set 1 – Digital Wallet Application

This folder contains the completed Jira Scrum assignment for the Digital Wallet Application.

The project demonstrates Scrum practices such as Epic and user story creation, sprint planning, task estimation, handling mid-sprint changes, impediment management and sprint progress tracking.

## Files Description

- **Set1_Digital_Wallet_Application.docx** – Detailed documentation of the project, including the work performed, sprint planning, scope change handling, impediment management, burndown analysis and retrospective.
- **report.pdf** – Exported Jira sprint report.
- **README.md** – Overview of the assignment and folder structure.
- **Screenshots/** – Screenshots showing the Jira space, Epic, user stories and sprint board.

## Topics Covered

- Jira Scrum space creation
- Epic and user story creation
- Story point estimation and velocity calculation
- Sprint planning and Sprint Goal
- Task breakdown and hour estimation
