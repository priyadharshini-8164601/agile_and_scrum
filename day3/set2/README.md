
# Insurance Claims Portal – Agile and Scrum

## Project Overview

This project focuses on planning an Insurance Claims Portal using the Agile Scrum methodology.

The portal allows customers to register insurance claims, upload supporting documents, track claim status, and receive settlement notifications.

## Project Details

- **Project Name:** Insurance Claims Portal
- **Project Key:** CLAIM
- **Methodology:** Agile Scrum
- **Tool Used:** Jira
- **Number of Epics:** 4
- **Number of User Stories:** 12
- **Total Story Points:** 33

## Project Epics

1. **Claim Registration** – Enter policy details, provide incident information, and submit claims.
2. **Document Upload** – View required documents, upload files, and verify uploaded documents.
3. **Claim Tracking** – View submitted claims, current status, and progress updates.
4. **Settlement Notifications** – Receive approval, rejection, and settlement notifications.
