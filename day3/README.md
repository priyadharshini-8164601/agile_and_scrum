## Day 3 – Agile and Scrum Case Studies

Day 3 contains three case-study assignments completed using Agile Scrum concepts and Jira.

### Set 1 – Online Grocery Delivery Application
- Product vision and Scrum roles
- Epics and user stories
- INVEST principles
- Acceptance criteria
- MoSCoW prioritisation
- Fibonacci story point estimation
- Definition of Ready (DoR) and Definition of Done (DoD)
- Jira Scrum board implementation

### Set 2 – Insurance Claims Portal
- Product vision
- Waterfall vs Agile comparison
- Epics and user stories
- INVEST principles and vertical slicing
- Acceptance criteria
- Planning Poker and story point estimation
- Definition of Done (DoD)
- Scrum roles, events, and artifacts
- Jira workflow management

### Set 3 – Hospital Appointment Booking Application
- Product vision
- Epics and user stories
- INVEST principles
- Acceptance criteria
- Business value vs effort prioritisation
- Planning Poker and story point estimation
- Definition of Ready (DoR) and Definition of Done (DoD)
- Stakeholder mapping
- Jira Scrum board implementation

**Note:** Jira screenshots and implementation evidence are included directly in the respective Word documentation files.
