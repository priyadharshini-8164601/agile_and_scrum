# Online Grocery Delivery Application – Agile and Scrum

## Project Overview
This project is part of the Day 3 Agile and Scrum training assignment. It focuses on creating and managing a product backlog for an Online Grocery Delivery Application using Jira Software.

## Project Details
- **Project Name:** Online Grocery Delivery Application
- **Project Type:** Scrum
- **Tool:** Jira Software
- **Epics:** 3
- **User Stories:** 12
- **Total Story Points:** 33

## Epics
1. Browse and Search
2. Cart and Checkout
3. Delivery and Order Tracking

## Concepts Covered
- Product Vision and Scrum Roles
- Epics and User Stories
- INVEST Checklist and Story Refinement
- Given / When / Then Acceptance Criteria
- MoSCoW Prioritisation
- Fibonacci Story Point Estimation
- Planning Poker
- Definition of Ready (DoR)
- Definition of Done (DoD)

## Project Structure
- **Documentation:** Product vision, Scrum roles, user stories, INVEST review, acceptance criteria, prioritisation, estimation and DoR/DoD.
- **Jira Screenshots:** Project creation, epic creation, story creation, story-point estimation, MoSCoW allocation and board workflow.

## Jira Workflow
The backlog was organised and monitored using the Jira Scrum board.

## Outcome
The assignment demonstrates how Agile and Scrum practices can be used to organise, prioritise and manage an online grocery delivery application's product backlog.
