
# Hospital Appointment Booking Application – Agile and Scrum

## Project Overview

This project focuses on planning a Hospital Appointment Booking Application using the Agile Scrum methodology.

The application allows patients to search for doctors, view available appointment slots, book appointments, reschedule or cancel appointments, and receive appointment reminders.

It also helps doctors manage their schedules and hospital administrators block unavailable slots.

## Project Details

- **Project Name:** Hospital Appointment Booking Application
- **Project Key:** HOSP
- **Methodology:** Agile Scrum
- **Tool Used:** Jira
- **Number of Epics:** 4
- **Number of User Stories:** 12
- **Total Story Points:** 36

## Project Epics

1. **Appointment Booking** – Search for doctors, view available slots, and book appointments.
2. **Rescheduling and Cancellation** – View, reschedule, and cancel appointments.
3. **Appointment Reminders** – Receive booking confirmations, reminders, and schedule-change notifications.
4. **Doctor Schedule Management** – View daily appointments, update available slots, and block unavailable slots.
